# Sentinel — AI Fraud Detection System

A portfolio project that demonstrates a machine-learning workflow for classifying potentially fraudulent transactions, exposing predictions through FastAPI, and presenting results in a Streamlit dashboard.

> **Important:** This project uses synthetic data generated by `generate_data.py`. It is an educational demonstration, not a production banking fraud system and not suitable for real financial decisions.

## Features

- Reproducible synthetic transaction dataset (6,000 rows)
- Random Forest classifier with SMOTE inside an imbalanced-learn pipeline
- Train/test split with stratification; SMOTE is applied only to training data
- Evaluation with precision, recall, F1-score, confusion matrix, and ROC-AUC
- FastAPI endpoints: `/health` and `/predict`
- Streamlit dashboard with risk assessment, session KPIs, charts, transaction table, and CSV export

## Tech Stack

Python, pandas, NumPy, scikit-learn, imbalanced-learn, FastAPI, Uvicorn, Streamlit, Requests.

## Run Locally

Create and activate a virtual environment, then install dependencies:

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Generate data and train the model:

```bash
python generate_data.py
python train_model.py
```

Start the API in one terminal:

```bash
uvicorn app:app --reload
```

Start the dashboard in another terminal:

```bash
streamlit run dashboard.py
```

Open the dashboard at http://localhost:8501 and API docs at http://127.0.0.1:8000/docs.

## Deployment

The included `render.yaml` describes two Render web services. The API build generates synthetic data and trains the model before starting Uvicorn. The dashboard uses the API service host supplied through the `API_URL` environment variable.

## Evaluation

Model metrics are printed by `python train_model.py` and depend on the generated synthetic dataset and model configuration. Do not interpret these scores as evidence of real-world banking performance.
